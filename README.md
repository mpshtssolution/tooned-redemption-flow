# Tooned Redemption Flow

Corporate gift redemption experience for Tooned.

Built as a standalone Next.js/Vercel application. This project is intentionally separate from the existing Tooned retail site.

## Phase 1

Polished, playful, fully clickable redemption-flow prototype with dummy data.

## Planned stack

- Next.js + Vercel
- Neon Postgres
- Vercel Blob for customer photo uploads
- Stripe for optional upgrades
- Google Sheets for fulfilment handoff
- Slack notifications
